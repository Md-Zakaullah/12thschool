# Vidya Campus: School + Hostel (starter)
1. `npm install`
2. Supabase SQL Editor mein `supabase/schema.sql` run karo
3. `.env.example` ko `.env.local` banao, keys bharo
4. Supabase Auth mein user banao, phir SQL ke last comment se use admin banao
5. `npm run dev` -> http://localhost:3000
6. GitHub push -> Vercel import -> same env vars
